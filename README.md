# 🌦️ Weather App - Pronóstico del Tiempo

Una aplicación web sencilla y limpia que permite a los usuarios obtener el pronóstico del tiempo en tiempo real para cualquier ciudad del mundo, utilizando la API de OpenWeatherMap.

## ✨ Características Principales

* **Búsqueda por Ciudad:** Ingresa el nombre de cualquier ciudad para obtener los datos del clima.
* **Datos en Tiempo Real:** Muestra información actualizada directamente desde la API de OpenWeatherMap.
* **Información Detallada:**
    * **Temperatura** en grados Celsius (°C).
    * **Descripción** del clima (ej. "cielo despejado", "nubes dispersas").
    * **Icono del Clima** que representa visualmente el estado actual.
    * **Nombre** de la ciudad y **país**.
* **Manejo de Errores:** Alertas para el usuario si la ciudad no se encuentra o si el campo está vacío.
* **Interfaz Limpia:** Un diseño minimalista para una fácil interacción.

## 🛠️ Stack Tecnológico

* **JavaScript (Puro):** Para la lógica de la aplicación, el manejo de eventos y las llamadas a la API (`async/await` con `fetch`).
* **HTML5:** Para la estructura del contenido.
* **CSS3:** Para el diseño y la presentación visual.
* **API Externa:** [OpenWeatherMap API](https://openweathermap.org/) para la obtención de los datos del clima.
